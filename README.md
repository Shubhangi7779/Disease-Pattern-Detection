# Disease Pattern Detection System

## Problem Statement
Healthcare organizations collect vast amounts of patient health data. Analyzing this data manually is complex and time-consuming. This project builds a machine learning pipeline to detect disease patterns and predict diabetes.

## Objectives
* Perform Exploratory Data Analysis (EDA) on patient records.
* Implement KMeans Clustering for patient grouping.
* Train a Random Forest Classifier for disease prediction and evaluate accuracy.

## Tech Stack
* Python
* Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
